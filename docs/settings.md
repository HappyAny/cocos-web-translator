# 配置说明

## Profile

在设置页新建或重命名 Profile。下拉框切换编辑对象；这里的操作不会替网页选择 Profile。在网页小菜单选择运行对象，该选择按最外层网页的域名和路径保存，查询参数和片段不参与绑定。首次遇到未绑定网页时会提示选择，选择前保持原文。

Profile 区只管理名称、额外 Prompt、自动缓存和个人修订。一个 Profile 可绑定多个网页；需要隔离术语与缓存时请分别新建。新建 Profile 自动使用共用服务，可选复制当前已保存的额外 Prompt，不复制缓存。最多 50 个 Profile，名称 1–80 字符。

上方的翻译服务、API 地址、模型、密钥、Body、思考参数、超时、目标语言、插件界面语言、预翻译、对白参考、字体及文字开关都是共用设置。修改后所有正在运行的 Profile 同步，新 Profile 无需重复填写。暂停、免密钥提交预算与用量、最多两条请求的并发上限也共用。

“保存共用设置”只保存上方配置；“保存额外 Prompt”只保存当前 Profile 的 Prompt。共用服务区的“试译一句”保存共用配置后，使用当前 Profile 已保存的 Prompt 请求翻译，不会保存或丢弃尚未保存的 Prompt。“试译当前 Profile”会保存当前填写的共用配置与 Prompt，再请求翻译。切换 Profile 不会丢弃尚未保存的共用配置。

旧版升级时沿用设置页正在编辑的 Profile 的服务与翻译选项，保留原全局暂停和界面语言；页面显示迁移来源。旧的各 Profile 配置备份保存在浏览器可信扩展存储中，不包含会话密钥，不发送到网页或翻译服务。既有 Prompt、绑定、缓存与个人修订保持独立，默认 Profile 仍使用原数据库。

## 翻译服务

MyMemory 适合免密钥试用，译文质量和额度受服务商限制。每日提交预算仅计算实际提交文字，缓存和内置词表不计入。

OpenAI 兼容 API 使用 Chat Completions 格式。填写基础地址、模型名称和密钥，保存时授权对应 API 域名。也可填写本地模型的 HTTP 地址。地址不要重复添加 `/chat/completions`。

“检查连接”不发送密钥，也不调用模型；HTTP 401 / 403 表示收到接口响应。两个试译按钮均实际请求当前接口，绕过缓存及个人修订，不使用对白历史。

## 额外 Prompt

每个 Profile 可以填写最多 12000 字符的模型翻译提示。例如：

```text
角色名：アリス = 爱丽丝；ボブ = 鲍勃
菜单：ホーム = 主界面；設定 = 设置
对白使用自然口语，同一角色的称谓保持一致。
```

Prompt 会添加到模型的系统消息，仅模型 API 使用。修改后自动翻译使用不同的缓存键；旧缓存仍保留。设置了模型 Prompt 后，内置菜单词表交由模型处理，个人修订仍具有最高优先级。确定的名称或菜单映射也可以直接保存为个人修订，离线生效。

## Body 和禁止思考

附加 Body JSON 填写请求顶层参数，例如：

```json
{ "temperature": 0.1, "max_tokens": 512 }
```

不要加 SDK 的 `extra_body` 外层。`model`、`messages` 和 `stream` 由扩展管理。密钥使用专用字段。

禁止思考预设：DeepSeek 使用 `thinking.type = disabled`，Qwen 使用 `enable_thinking = false`，vLLM 使用 `chat_template_kwargs.enable_thinking = false`。选择自定义时，在 Body 中填写服务支持的参数。只有支持相应参数的模型才会生效。

## 预翻译与历史

提前翻译 0–20 句。0 仅当前对白；角色名随对白处理，不占句数。

历史参考默认关闭。开启后只保留最近 N 句已显示的角色名、原对白和译文；默认 10、可设 1–20，暂停不会使其过期。历史仅供模型 API 使用，可能增加 token 用量；免密钥服务不发送历史。

## 个人译文

导出当前 Profile 和目标语言的 JSON，修改译文后导入合并，也可在设置页保存单句修订。个人修订优先于自动缓存、词表及在线请求。文件包含 Profile 名称和 ID 作为标识；导入始终写入当前编辑的 Profile，不会自动切换或创建 Profile。

```json
{
  "format": "cocos-translations",
  "version": 1,
  "sourceLanguage": "ja",
  "targetLanguage": "en",
  "translations": { "設定": "Settings" }
}
```

保留原文键、富文本标签及目标语言。导入上限为 10 MB、20000 条；文件不得包含 API 密钥。导入语言需与当前保存的目标语言一致。兼容旧版同结构导出文件；未设置目标语言的旧文件按简体中文处理。

清空自动缓存只影响当前 Profile 的自动记录，不会删除它的个人修订，也不影响其他 Profile。切换目标语言后分别读取该语言的缓存与修订。

## 缓存

持久缓存保存在浏览器 IndexedDB。SHA-256 根据服务参数、Prompt、目标语言、原文和可选对白参考生成键。每个 Profile 使用独立数据库，默认 Profile 继续使用原缓存数据库。

运行期间用 JavaScript Map 保存 LRU 热缓存，包括未命中的读取结果；重复并发读取会合并。所有 Profile 共用最多 2000 条、约 4 MiB 数据预算，缓存键复用另有约 2 MiB 预算。淘汰热缓存不删除 IndexedDB 记录。后台休眠后下次可从持久缓存读取；首次翻译延迟仍取决于服务。JSON 导出是生成本地可编辑文件的方式。
